🌸 BaiiSelf — Game Review Hub

A personal video game review website where you can discover games, explore reviews, and share your gaming experiences.

✨ Features

- 🎮 Game Collection — Browse video games from different genres.
- ⭐ Review Scores — Display ratings for each game.
- 🖼️ Game Cover Images — Show cover art on game cards.
- 📝 Personal Reviews — Read game reviews and comments.
- 🔍 Search & Categories — Find games by name or genre.
- 🌷 Screenshot Slideshow — View in-game screenshots in the View Review section using left and right navigation.
- 💙 Soft Blue Floral Theme — A clean white, light blue, and navy design decorated with flowers.
- 📱 Responsive Design — Supports desktop and mobile screens.

🖼️ How to Add Game Screenshots

You can add screenshots for each game directly to your GitHub repository.

Step 1: Open Your Repository

Go to your GitHub repository: "game-review-hub"

Step 2: Create an Images Folder

1. Click Add file.
2. Select Create new file.
3. Enter "images/elden-ring/README.md" as the filename.
4. Add a short description and commit the file.

This creates a folder for the game's images.

Step 3: Upload Screenshots

1. Open the "images/elden-ring/" folder.

2. Click Add file → Upload files.

3. Select your screenshots.

4. Use these filenames:
   
   - "cover.jpg" — Game cover image
   - "scene-1.jpg" — First screenshot
   - "scene-2.jpg" — Second screenshot
   - "scene-3.jpg" — Third screenshot

5. Click Commit changes.

Repeat these steps for other games, using the appropriate folder name.

Important: The filenames and folder paths must match the paths referenced in "index.html". If your screenshots use ".png" or another extension, update the corresponding paths in the code.

🚀 How to Publish with GitHub Pages

1. Open your repository on GitHub.
2. Go to Settings → Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Choose the "main" branch.
5. Select "/(root)" as the folder.
6. Click Save.
7. Wait for GitHub Pages to deploy your website.

Your website URL will generally look like:

"https://YOUR-USERNAME.github.io/game-review-hub/"

Replace "YOUR-USERNAME" with your GitHub username.

🔄 Updating Your Website

Whenever you want to update your website:

1. Edit "index.html" or upload new images.
2. Commit your changes to the "main" branch.
3. Wait for GitHub Pages to rebuild the website.
4. Refresh your website to see the changes.
